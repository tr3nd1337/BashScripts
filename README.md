# Bash Scripts

A collection of Bash scripts written while practising Linux, scripting and cybersecurity.

### Scripts

- **hello_loop.sh** → A simple Bash `for` loop that generates numbers from 0000 to 0999 using `printf` and zero-padding.
- **pin_brute_force.sh** → Local PIN brute-force simulation.
- **password_generator.sh** → Random password generator.
- **log_analyser.sh** → Basic log analysis and parsing.
